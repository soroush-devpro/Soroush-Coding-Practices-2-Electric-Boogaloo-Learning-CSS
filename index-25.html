I have not created a custom image rollover sprite, so I will be using yesterday's background iamge and shifting it over when hovered and clicked! The button is nonfunctional since its type attribute has a value of button, so you can hover and click on it as much as you want (by default, buttons in HTML are submit buttons, as if they have a type attribute with a value of submit, meaning if they're placed inside a form, they try to submit the form to the server; by setting the type attribute's value to button, it creates a generic, nonfunctional button that doesn't attempt to send anything to any form servers).
