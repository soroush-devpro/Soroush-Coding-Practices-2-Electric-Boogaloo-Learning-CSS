Hello everyone, and welcome to Day 22 of these coding practices! Today, we will be diving into the wonderful world of responsive web design by doing a practice of Flexbox! Since I am using the HTML and CSS book by Jon Duckett to learn HTML and CSS (which was published nearly 15 years ago in late 2011), the book does not cover Flexbox and instead teaches multi-column layouts through floats, which are outdated nowadays. So, I have used this amazing game called Flexbox Froggy to learn some Flexbox! I won't be practicing everything about Flexbox I've learned; I will practice just one thing: Making multi-column layouts with the justify-content property! We will also be using its vertical counterpart, the align-items property, to make all the boxes clump up at the top of the page and only be as tall as they need to be — by default, all flex items are set to be as tall as the tallest box (the default value for align-items is stretch), but I fixed that! (While I learned align-items from Flexbox Froggy, applying it to make all the boxes just as tall as they need to be, effectively clumping them up together towards the top of the page, was a trick I learned from Google; I also learned the term "flex items" from Google!)

As you can see, every column is equally spaced across the page thanks to the space-evenly value for the justify-content property, which spaces all three boxes equally with equal space between and around them. This is a value that Flexbox Froggy did not immediately present to me, but that I learned through Google (and later saw in Flexbox Froggy when I clicked on the justify-content property and saw all possible values, including space-evenly; I think the reason why it wasn't immediately introduced to me in the list of properties on Level 1 of Flexbox Froggy is that space-evenly was not a value of justify-content that was useful in any level of Flexbox Froggy; space-between and space-around were more communly used — space-evenly is, to my understanding, a mix of both!).
