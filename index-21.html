Day 21: Floats!

Hello everyone, and welcome to Day 21 of these coding practices! Today, we'll be diving into the wonderful world of floats: using normal flow (otherwise known as static positioning), relative positioning, absolute positioning, fixed positioning, z-indexes, and floating elements! We are using our older webpage layout (without centered boxes with a cool drop shadow) so we can demonstrate floats more clearly, and I have placed <div> containers around each section since the absolute positioning section requires a container, so I figured I'd give them all <div> containers for consistency (I have also wrapped the entire main text other than the fixed-positioned header in a <div> container so I could shift the main teext down by setting its top margin to 7em with the margin-top property, so that way, the header doesn't overlap with the text at the very top of the page). Through the autofill options of Visual Studio Code, I also discovered the font-weight property has a normal value, which I am using in the explanations inside the headers introducing each section to ease the strain on the eyes that would come with all of it being bold. Through Google (as in, outside of the HTML and CSS book by Jon Duckett that I'm using to learn HTML and CSS), I also learned the :not pseudo-class, allowing me to make all <div> elements other than the one containing the float section (with an id of float) have a width of 75%. While back in the day, floats were used to make columns/position things side-by-side and things like that, that is now outdated, thanks to Flexbox. I am using the HTML and CSS book by Jon Duckett to learn HTML and CSS, which was published before Flexbox was released, so I will be using Flexbox Froggy to learn! Thus, we will be skipping the entire rest of the "Layout" chapter of the HTML and CSS book by Jon Duckett, and instead using some of what I've learned from Flexbox Froggy to make some basic multi-column layouts. The heading of this page uses and illustrates fixed positioning and the z-index property, and this paragraph demonstrates normal flow (I believe another name for it is static positioning)!

Absolute Positioning: Moving and taking an element out of normal flow, causing it to no longer affect the position of other elements in the page (the other elements act like it isn't there). It is placed in relation to its containing element. Fixed positioning (which is what the header of this page uses) is a type of absolute positioning that is based on the browser window, not the containing element.
